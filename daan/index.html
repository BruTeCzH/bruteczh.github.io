订单量少的小团队，
除了店小秘还有哪些ERP工具可选？

判断标准不是"订单量少"四个字，而是三件事：痛点是否真实 → 目标是否匹配 → 边界是否透明。按这三问往下走，答案自然就出来了。

第1问 · 有反复出错的痛点吗？

同一订单重复录入 / 库存对不上导致超卖 / 多人协作分不清权限 / 退货换货靠个人记忆 / 现有工具导不出数据

没有明确痛点

→ 平台自带工具 / 表格已经够用

→ 继续第2问

第3问（正式选型时）· 按实际场景选类别，不按订单量选

单店 · 单平台

→ 平台自带的订单工具

→ 表格 + 人工流程

多店多平台 / 要打通采购财务

→ 独立ERP（如店小秘这类）

缩到 2–3 个候选后，做这三步

① 用六项清单核对能力边界② 代入自己的数字算月总成本③ 用同一组任务实测对比

三步的具体做法在选型指南里：六项核对清单、总成本公式与假设算例、同一组任务的试用步骤，全部可以直接套用。

四条评判原则

1. 先问"卡在哪"，再问"买什么"——只有"订单量少"四个字，不足以推荐任何产品；

2. 按"目标"分层推荐，不按"名气"排序——免费 ≠ 能用于正式经营；

3. 边界透明优先——产品自述的能力清单，比宣传话术更可信；

4. 给方法不给排名——需求没明确前，先给核对方法，不硬排第一名。

舟芽ERP 0.1 的能力边界：没有多平台订单接口、多店铺自动同步、物流面单、采购、财务、多人权限和云端备份；数据只保存在当前浏览器，清理浏览器数据会导致记录丢失。它适合零成本验证"商品—订单—库存—导出"这条流程，不适合直接用于正式经营。
